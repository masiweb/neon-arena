- فروشگاه طلا و الماس، سفارش خرید و تأیید یا رد مدیر

- فایل‌های رابط و موتور رندر داخل APK هستند؛ سرور وضعیت معتبر بازی، اتاق‌ها و حساب‌ها را هماهنگ می‌کند

## نصب کامل روی Ubuntu 24.04

ابتدا رکورد `A` دامنه را روی IP سرور قرار دهید و پورت‌های `80` و `443` را باز کنید. سپس:

```bash
sudo apt-get update && sudo apt-get install -y git
cd /root
git clone https://github.com/masiweb/neon-arena.git
cd /root/neon-arena
sudo bash install.sh --domain game.chanelchat.ir --ssl
```

نصب‌کننده به‌صورت خودکار Python، محیط مجازی، Nginx، Node.js، Java 17 JDK کامل، Gradle 8.7، Android SDK 35، Build Tools 34/35 و Certbot را نصب می‌کند. قبل از انتشار، تست‌های واحد و تست واقعی HTTP/WebSocket را اجرا می‌کند، APK را می‌سازد و امضایش را بررسی می‌کند. نسخه جدید فقط پس از health check موفق فعال می‌شود و در خرابی، نسخه سرور قبلی برمی‌گردد.

داده کاربران در مسیر مستقل زیر نگه‌داری می‌شود و با ارتقای کد حذف یا جایگزین نخواهد شد:

```text
/var/lib/neon-arena/neon-arena.db
```

تنظیمات محرمانه اختیاری در `/etc/neon-arena.env` قرار می‌گیرد.

نسخه وب و APK نهایی:

```text
https://game.chanelchat.ir
https://game.chanelchat.ir/static/neon-arena-android-latest.apk
```

برای نصب سبک و بدون ابزار ساخت APK:

```bash
sudo bash install.sh --domain game.chanelchat.ir --ssl --skip-android
```

## ساخت اولین مدیر

حساب مدیر را مستقیماً روی سرور بسازید. رمز از ورودی استاندارد خوانده می‌شود تا داخل تاریخچهٔ Shell ذخیره نشود:

```bash
read -rsp 'Initial admin password: ' ADMIN_PASSWORD; echo
printf '%s' "$ADMIN_PASSWORD" | sudo -u neonarena \
  NEON_DATABASE=/var/lib/neon-arena/neon-arena.db \
  /opt/neon-arena/venv/bin/python -m server.manage create-admin \
  --email admin@example.com --username neon_admin --password-stdin
unset ADMIN_PASSWORD
```

پنل در نشانی `/admin` در دسترس است. حساب ساخته‌شده در اولین ورود قفل است و مدیر باید رمز اولیه را با رمزی حداقل ۱۴ کاراکتری شامل حروف بزرگ و کوچک، عدد و نماد جایگزین کند. تا آن زمان همهٔ APIهای مدیریتی پاسخ `428` می‌دهند.

## بازیابی رمز عبور با ایمیل

فایل `/etc/neon-arena.env` را با سرویس ایمیل خود تکمیل کنید:

```dotenv
NEON_SMTP_HOST=smtp.example.com
NEON_SMTP_PORT=587
NEON_SMTP_USER=no-reply@example.com
NEON_SMTP_PASSWORD=CHANGE_ME
NEON_SMTP_FROM=no-reply@example.com
```

سپس `sudo systemctl restart neon-arena` را اجرا کنید. اگر SMTP خالی باشد، پاسخ فراموشی رمز عمداً وجود یا نبود حساب را افشا نمی‌کند، اما ایمیلی ارسال نمی‌شود. `NEON_DEV_RESET=1` فقط برای محیط آزمایشی است.

## گفت‌وگوی صوتی و TURN

ارتباط مستقیم با STUN پیش‌فرض فعال است. برای پایداری صدا روی اینترنت موبایل و NATهای سخت، coturn را تنظیم و این مقادیر را در `/etc/neon-arena.env` قرار دهید:

```dotenv
NEON_TURN_URL=turn:turn.example.com:3478?transport=udp
NEON_TURN_USERNAME=neon
NEON_TURN_CREDENTIAL=CHANGE_ME
```

پورت TURN باید در فایروال باز باشد. اطلاعات ICE فقط پس از ورود معتبر به اتاق برای کلاینت ارسال می‌شود.

## ارتقا، پشتیبان‌گیری و انتقال سرور

```bash
cd /root/neon-arena
git pull --ff-only origin main
sudo bash install.sh --domain game.chanelchat.ir --ssl
```

پشتیبان‌گیری سازگار SQLite:

```bash
sudo -u neonarena sqlite3 /var/lib/neon-arena/neon-arena.db \
  ".backup '/root/neon-arena-backup.db'"
```

برای انتقال، سرویس قدیمی را متوقف و کل مسیر `/var/lib/neon-arena` را منتقل کنید. دیتابیس در `neon-arena.db` و کلید پایدار APK در `signing/debug.keystore` است؛ انتقال هر دو باعث می‌شود اطلاعات کاربران حفظ شود و Android نسخه جدید را ارتقای همان برنامه تشخیص دهد. پس از انتقال، مالک دیتابیس باید `neonarena:neonarena` و مالک پوشه `signing` باید `root:root` با مجوز `0700` باشد.

## توسعه و تست

```bash
python3 -m venv .venv
.venv/bin/pip install -r server/requirements.txt
./verify.sh --python .venv/bin/python --integration
```

تست‌ها منطق حرکت و برخورد، نقشه‌ها، آسیب، نارنجک/RPG، تیر خودی، مالک اتاق، حساب‌ها، معرفی، دوستان، تیم ۶نفره، فروشگاه، پاداش تکرارنشدنی و جریان واقعی دو کلاینت WebSocket را پوشش می‌دهند.

ساخت APK مستقل:

```bash
cd android
GAME_SERVER_ORIGIN=https://game.chanelchat.ir ./build-apk.sh
```

کلیدهای دسکتاپ: `WASD` یا جهت‌ها، کلیک چپ شلیک، `Space` پرش، `Shift` شتاب، `E` سپر، `G` نارنجک و `R` موشک RPG.
