# نبرد نئون — بازی چندنفره موبایلی تحت وب

یک بازی اکشن سبک و فوری برای جمع‌های دوستانه. بازیکن می‌تواند از مرورگر یا اپ اندروید وارد یک اتاق خصوصی شود.

نسخه فعلی: **1.8.0** — پروتکل شبکه: **4**

- نمای اول‌شخص سبک و مناسب موبایل
- کاراکترهای آدمک نئونی در میدان
- مینی‌مپ زنده با نمایش موقعیت بازیکنان
- جایزه اختفای ۱۰ ثانیه‌ای از نقشه حریفان

## امکانات نسخه اول

- بازی هم‌زمان ۲ تا ۱۲ نفر با WebSocket
- ساخت اتاق چهارحرفی و دعوت با لینک
- کنترل افقی موبایل با جوی‌استیک حرکت و نشانه‌گیری/شلیک
- حرکت نرم ۴۵ تیک در ثانیه، ورودی آنالوگ و پیش‌بینی حرکت روی خود گوشی
- هدف‌گیری خودکار نزدیک‌ترین حریف، شلیک هم‌جهت حرکت و نشانه‌گیری دستی
- موسیقی زمینه و افکت صوتی شلیک با امکان قطع صدا
- اجرای تمام‌صفحه برای حذف مزاحمت نوار آدرس مرورگر
- سه جان برای هر بازیکن، حذف نهایی و تماشای ادامه راند
- جایزه‌های میدانی دوره‌ای: سرعت، خون اضافه، سپر، سلاح قوی‌تر و اختفا از نقشه
- انتخاب یکی از سه سلاح قوی‌تر توسط برنده برای راند بعد
- راند دو دقیقه‌ای یا باقی ماندن آخرین بازیکن
- جدول امتیاز، تمام‌صفحه و بازخورد لرزشی گوشی
- کنترل جایگزین کامپیوتر: WASD، ماوس، Shift و E
- موتور سبک و بدون دیتابیس؛ مناسب Ubuntu 24.04 و سرور 1GB RAM
- اپ اندروید تمام‌صفحه با فایل‌های HTML/CSS/JS داخلی و اتصال امن به سرور بازی
- پیش‌بینی فوری حرکت و تیر در APK، تأیید نتیجه توسط سرور و اصلاح نرم اختلاف موقعیت
- افزودن و حذف بازیکن بات توسط سازنده اتاق، با حرکت، هدف‌گیری، شلیک و استفاده از قابلیت‌ها

## نصب سریع روی Ubuntu 24.04

روی Ubuntu 24.04 خام، مخزن را دریافت و نصب کامل را اجرا کنید:

```bash
sudo apt-get update && sudo apt-get install -y git
git clone https://github.com/masiweb/neon-arena.git
cd neon-arena
sudo bash install.sh --domain game.example.com --ssl
```

اسکریپت به‌صورت خودکار Python، Nginx، Java 17، Gradle 8.7، Android CLI، Android API 35 و Build Tools نسخه‌های 34 و 35 را نصب می‌کند؛ سپس سرور و APK نسخه جاری را آماده می‌کند.

صفحه ورود همیشه دکمه دانلود اندروید را با نشانی ثابت زیر نمایش می‌دهد و نصب‌کننده در هر ارتقا فایل آن را با جدیدترین APK جایگزین می‌کند:

```text
https://game.example.com/static/neon-arena-android-latest.apk
```

اگر روی یک سرور سبک فقط وب‌سرور را می‌خواهید و ساخت APK لازم نیست:

```bash
sudo bash install.sh --domain game.example.com --ssl --skip-android
```

اگر فعلاً دامنه ندارید:

```bash
sudo bash install.sh --domain YOUR_SERVER_IP
```

بعد از پایان نصب، آدرس نمایش‌داده‌شده را با گوشی باز کنید. یک نفر «ساخت اتاق جدید» را می‌زند و لینک دعوت را برای بقیه می‌فرستد.

مرورگرها فقط بعد از لمس کاربر اجازه تمام‌صفحه می‌دهند. دکمه‌های ساخت/ورود به اتاق این درخواست را خودکار ارسال می‌کنند و دکمه `⛶` نیز همیشه داخل بازی در دسترس است.

برای ارتقا از نسخه قبلی، ZIP جدید را استخراج و همان دستور نصب را دوباره اجرا کنید؛ سرویس با کد جدید به‌صورت خودکار ری‌استارت می‌شود.

## نسخه اندروید

پروژه APK در پوشه `android/` قرار دارد. فایل‌های رابط بازی هنگام build داخل APK کپی می‌شوند؛ فقط وضعیت آنلاین بازی از طریق HTTPS و WebSocket از `game.chanelchat.ir` دریافت می‌شود. حداقل نسخه موردنیاز Android 7 است.

برای ساخت نسخه آزمایشی نصب‌شدنی با Java 17، Android SDK 35 و Gradle 8.7:

```bash
cd android
chmod +x build-apk.sh
./build-apk.sh
```

خروجی در `android/app/build/outputs/apk/debug/app-debug.apk` ساخته می‌شود. Workflow آماده GitHub Actions نیز در `.github/workflows/build-android.yml` وجود دارد.

## شرایط دامنه و SSL

برای SSL باید رکورد A دامنه از قبل به IP سرور اشاره کند و پورت‌های 80 و 443 باز باشند. اگر فقط با IP نصب کنید، بازی با HTTP اجرا می‌شود.

## دستورات مدیریت

```bash
sudo systemctl status neon-arena
sudo systemctl restart neon-arena
sudo journalctl -u neon-arena -n 100 --no-pager
```

بررسی سلامت:

```bash
curl http://127.0.0.1:8765/health
```

## اجرای آزمایشی بدون Nginx

```bash
chmod +x start-dev.sh
./start-dev.sh
```

سپس `http://SERVER_IP:8765` را باز کنید. برای دسترسی از اینترنت باید پورت 8765 در فایروال باز باشد؛ نصب اصلی با Nginx توصیه می‌شود.

## نکات فنی مهم

- وضعیت اتاق‌ها در RAM نگهداری می‌شود و با ری‌استارت سرویس پاک می‌شود؛ برای این سبک بازی فوری طبیعی است.
- سرویس عمداً با یک worker اجرا می‌شود تا همه بازیکنان یک اتاق به وضعیت مشترک دسترسی داشته باشند.
- برای سرورهای بزرگ‌تر می‌توان وضعیت اتاق‌ها را بعداً به Redis منتقل و چند worker فعال کرد.

