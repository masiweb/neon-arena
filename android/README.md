# Neon Arena Android

این پروژه یک پوسته اندروید سبک و سخت‌افزارشتاب‌داده‌شده است. فایل‌های HTML، CSS و JavaScript هنگام ساخت داخل APK قرار می‌گیرند و برنامه فقط برای API و WebSocket به `https://game.chanelchat.ir` متصل می‌شود.

- حداقل اندروید: 7.0 (API 24)
- جهت اجرا: افقی
- حالت نمایش: Immersive Fullscreen
- نسخه برنامه: 1.8.0
- نسخه پروتکل سرور: 4

ساخت آزمایشی:

```bash
chmod +x build-apk.sh
./build-apk.sh
```

خروجی:

```text
app/build/outputs/apk/debug/app-debug.apk
```
